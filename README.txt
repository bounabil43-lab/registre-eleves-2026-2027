تطبيق سجل التلاميذ 2026-2027 — نسخة PWA

المميزات:
- يعمل على الهاتف والكمبيوتر.
- قابل للتثبيت على الشاشة الرئيسية مثل التطبيق.
- يعمل بملء الشاشة بعد التثبيت.
- البحث والفلترة والإحصائيات وبطاقة التلميذ.
- استيراد Excel من داخل التطبيق.
- تخزين البيانات المستوردة محليًا.

النشر:
ارفع جميع الملفات معًا إلى GitHub Pages أو أي استضافة HTTPS:
index.html
manifest.json
service-worker.js
icon.svg

بعد النشر افتح الرابط من الهاتف:
Android/Chrome: القائمة ⋮ > تثبيت التطبيق / Add to Home screen.
iPhone/Safari: مشاركة > Add to Home Screen.

مهم:
Service Worker والتثبيت يحتاجان HTTPS عند النشر (GitHub Pages يوفر HTTPS).
